 Widdy - Gift Wishlist Application

A mobile application that allows users to create and manage gift lists for various occasions. Users can share their lists privately with friends and family, enabling others to choose gifts without revealing who selected what.

## About Widdy

Widdy simplifies gift-giving by providing an organized platform where users can create personalized wishlists for special occasions. Friends and family can view these lists, reserve gifts anonymously, and ensure that recipients get what they truly want without duplicate gifts.

 Key Features

### For Gift Owners
- **User Registration & Authentication** - Secure account creation and login
- **Wishlist Management** - Create, view, edit, and delete wishlists
- **Gift Item Management** - Add, edit, and remove gift items with detailed information
- **Sharing** - Share wishlists via unique 6-digit access codes
- **Real-time Updates** - See gift reservations instantly

### For Gift Givers
- **Guest Access** - View wishlists without account using access codes
- **Anonymous Reservation** - Reserve gifts without revealing identity
- **Gift Tracking** - See available and reserved items in real-time

## Technical Stack

- **Platform**: Android
- **Language**: Java
- **Backend**: Firebase (Authentication & Firestore)
- **Image Storage**: ImgBB API
- **Maps Integration**: Google Maps for store locations
